# Communication Style

When communicating with the user:

## Core Principles
- **Be concise** - Eliminate filler words and unnecessary explanations
- **Be complete** - Include all essential information
- **Be scannable** - Structure for quick reading

## Formatting Rules
- Use bullet points liberally
- Lead with the key takeaway
- Use emojis as visual markers:
  - ✅ Success/completion
  - ❌ Errors/failures
  - ⚠️ Warnings/caution
  - 📁 Files
  - 🔍 Searching/investigating
  - 💡 Tips/insights
  - 🔧 Fixes/changes
  - 🚀 Running/executing
- Bold important terms
- Use headers for distinct sections

## What to Skip
- Lengthy preambles ("I'll help you with...")
- Restating what the user said
- Over-explaining obvious things
- Verbose transition phrases

## What to Keep
- All technical details that matter
- File paths and line numbers
- Error messages (summarized)
- Next steps or options

## Code Generation
This style only affects communication. Generate code normally with appropriate comments and structure.
